# DK in-play studies: results

**Status: DK prices valid (amendment-4 checks passed; post-hoc calibration confirms).** Every gate below FAILs.
- **Robustness to stale prices:** a FAIL here holds even if some prices were stale; a PASS would not have. Stale prices
  mostly create fake edges (fills against an old price), so they bias toward PASS.
- **The Lead's 0–10 min test** (≥ 85% of matches decided in the last 10 min of the listing) came out at 71%. That end
  is not the end of play: in 87–97% of the matches whose last kept snapshot is 10+ min before the end of the listing,
  rule (c) cut a settled DK price right after that snapshot. The post-hoc calibration below settles validity instead.

Generated by `python -m upsets.dk_inplay_study`. Cached Odds API snapshots only (0 credits); aggregates only. Sample: 4,282 matches with a DK close in the in-play sample; 4,274 have a usable in-play DK quote (≤ 5 min old). P&L in units of the first stake; ROI = P&L / positions. In-play fills cut 0% / 3% / 6% of the winnings; the gate reads the 3% column. No 5-min snapshots were pulled, so the 10-min vs 5-min check can't be run. Pinnacle's in-play quotes in these snapshots barely move (see the report), so there is no fair in-play reference: Δ vs hold is realized only.

## Caveats (Lead review, 2026-10-29)
- **Reach-50% at a 10-min step undercounts touches.** A dog can touch 50% between snapshots, so 31.6% is a lower bound
  on the true reach rate, and part of the gap to the close's 39.5% is sampling. Kalshi's 1-min run (34.1% vs 38.4%,
  `reports/backtest_cashout.md` §6) is the cleaner number.
- **FAVDIP ≥ 80% is the same set as DOG50 with dog < 20%.**
  - A favourite at ≥ 80% is a dog at < 20%, and a favourite dipping to 50% is that dog reaching 50%.
  - So B's 117 / 93 / 210 bets are exactly DOG50's hedged positions, seen from the other side.
- **FAVDIP 60–80% B (1,079 bets) and DOG50 dog < 20% (1,079 positions) match by coincidence.** They come from different
  entries: 673 + 406 against 607 + 472.
