# Seeded players in early rounds: base rates (2010–2025)

Results only (no odds). Data: Jeff Sackmann's tennis_atp / tennis_wta match files (CC BY-NC-SA 4.0), via the archival fork phat-d0/tennis-sackmann-archive. Generated by `python -m upsets.seeds`.

Scope: tour-level knockout events (Slams, 1000s, other tour events; no team events, Finals or round-robin events), rounds 1–2 of the main draw. Void = walkover, or a retirement/default before set 1 is complete (left out). `elo` = mean pre-match Elo probability that the seed loses (overall Elo from 1990 on tour-level + qualifying/Challenger (ATP) / qualifying/ITF (WTA), ATP and WTA apart); `gap` = actual − Elo. `se` = binomial standard error of the rate.
